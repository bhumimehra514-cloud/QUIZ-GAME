# 🎯 Python Quiz Game

## About the Project
This is a simple interactive quiz game developed using Python and Streamlit.
The application allows users to answer multiple-choice questions and calculates their final score based on their answers.

## Features
Multiple-choice questions
User-friendly interface
Automatic score calculation
Result based on the final score
Interactive quiz experience

## Technologies Used
Python
Streamlit

## How to Run
1. Install Python.
2. Install Streamlit:
   pip install streamlit
3. Run the application:
   streamlit run QUIZ.py

## Project Purpose
This project was created to practice Python programming concepts such as lists, loops, conditional statements, and user input.
